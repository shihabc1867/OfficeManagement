OFFICE MANAGEMENT - ইন্সটলের নিয়ম (সহজ ধাপ)
==============================================

ফোল্ডারে দুইটি অংশ আছে:
  1_AppsScript   -> Google Apps Script-এ বসবে (অ্যাপের মূল অংশ)
  2_GitHubPages  -> GitHub Pages-এ বসবে (ইন্সটলযোগ্য অ্যাপের মোড়ক)

ক) Apps Script (একদম নতুন প্রজেক্ট, AUTHENTIC-এর সাথে মেশাবেন না)
1. script.google.com এ গিয়ে "New project" খুলুন। নাম দিন: Office Management।
2. 1_AppsScript ফোল্ডারের ফাইলগুলো একটি একটি করে বসান। ফাইলের নাম হুবহু এক হতে হবে:
   স্ক্রিপ্ট ফাইল (+ চাপ দিয়ে "Script"): Config, Db, Core, Auth, Notify, Admin, Tenant, Data, Test
   এইচটিএমএল ফাইল (+ চাপ দিয়ে "HTML"): Index, CssMain, JsCore, JsLang, JsAuth, JsAdmin, JsTenant, JsReports
   (নামের শেষে .gs/.html নিজে নিজে বসে যায়, লিখবেন না। আগের Code.gs ফাইলটি মুছে দিন।)
   প্রতিটি ফাইলের ভেতরের পুরো লেখা কপি করে পেস্ট করুন।
3. উপরের ফাংশন বাছাইয়ের জায়গা থেকে  setupDatabase  বাছাই করে ▶ Run চাপুন। অনুমতি চাইলে অনুমতি দিন।
4. নিচে "Execution log" এ লেখা আসবে:  ADMIN LOGIN  username: admin   password: ........
   এই পাসওয়ার্ড কোথাও লিখে রাখুন। (একই লগে Google Sheet-এর লিংকও থাকবে - এটাই ডাটাবেস।)
5. এরপর  diagnose  ফাংশন Run করে দেখুন সব ফাইল ঠিক আছে কি না।
6. Deploy -> New deployment -> Web app:
      Execute as: Me
      Who has access: Anyone
   Deploy চাপুন, আসা লিংকটি (শেষে /exec) কপি করুন।
   * পরে কোড বদলালে: Deploy -> Manage deployments -> ✎ -> Version: "New version" -> Deploy।

খ) GitHub Pages (ইন্সটলযোগ্য অ্যাপ)
1. GitHub-এ নতুন repository খুলুন (যেমন: office), Public রাখুন।
2. 2_GitHubPages ফোল্ডারের সব ফাইল সেখানে আপলোড করুন।
3. index.html খুলে  EXEC_URL  লাইনে ক-এর ৬ নম্বরের /exec লিংক বসান। Commit করুন।
4. Settings -> Pages -> Branch: main -> Save। কিছুক্ষণ পর লিংক পাবেন:  https://আপনার-নাম.github.io/office/
5. ওই লিংক ফোনের Chrome-এ খুললে "Install" আসবে। লগইন পেজের "Install Office Management App" বোতামও কাজ করবে।

গ) প্রথম লগইন ও সেটআপ (আপনি = অ্যাডমিন)
1. লগইন পেজের নিচের বাঁ কোণে "Admin login" চাপুন। username: admin, ধাপ ক-৪ এর পাসওয়ার্ড।
2. Settings -> "Change admin password" দিয়ে নিজের পাসওয়ার্ড দিন।
3. Settings-এ আপনার WhatsApp নম্বর (01XXXXXXXXX) ও GitHub Pages লিংক বসিয়ে Save করুন।
4. Settings-এ "Terms & Conditions" নিজের মতো লিখে "Save terms" দিন।
   (শর্ত বদলে সবাইকে আবার সম্মতি নিতে চাইলে "Ask everybody to agree again" টিক দিন।)
5. Categories-এ ডিফল্ট "Educational Institution" ও "Office" আছে। নতুন ক্যাটাগরি যোগ করার সময় বেছে নিন সেটি
   "Education" ধরনের (শিক্ষক/শিক্ষার্থী) না "Office" ধরনের (কর্মচারী/বেতন)।
6. Institutions -> Add institution: ক্যাটাগরি বাছুন -> "Create and show key"। আসা কি (XXXX-XXXX-XXXX)
   কপি করে বা "Send on WhatsApp" দিয়ে কোচিং/অফিসের প্রধানকে দিন। কি একবারই দেখা যায়।
   * প্রতিটি প্রতিষ্ঠানের আলাদা কি। এক ক্যাটাগরির কি অন্য ক্যাটাগরিতে চলে না।
   * কি প্রথমবার যে মোবাইল নম্বর দিয়ে ব্যবহার হবে, পরে শুধু সেই নম্বরেই চলবে।
7. প্রধান লগইন করবেন: ক্যাটাগরি, নাম, মোবাইল, প্রতিষ্ঠানের নাম, ঠিকানা ও সিক্রেট কি দিয়ে -> শর্ত পড়ে "Yes, I agree"।
   তখনই আপনার (অ্যাডমিনের) Agreements পেজে প্রমাণ জমা হবে (PDF-ও নামানো যায়) এবং নোটিফিকেশন আসবে।
8. প্রধান নিজে Assistants পেজ থেকে ৩ জন পর্যন্ত সহযোগী যোগ করতে পারবেন (সর্বোচ্চ ১০)। ৩ জনের বেশি
   চাইলে "Ask the admin" দিয়ে অনুরোধ পাঠাবেন; আপনি Requests পেজে Approve/Reject করবেন।
9. আপনি যেকোনো প্রতিষ্ঠানের পাশের "Open" চাপলে তার ভেতরে ঢুকে সবকিছু দেখতে ও বদলাতে পারবেন।
   ভাড়ার মেয়াদ শেষ হলে বা "Suspend" করলে সেই প্রতিষ্ঠানের সবাই আটকে যায় (ডাটা থাকে)।

কোন ক্যাটাগরিতে কী দেখা যায়
  Educational Institution: Teachers, Students, Attendance, Reports (সাপ্তাহিক, মাসিক, নিজের সময়; PDF সারাংশ,
                           দৈনিক শিট, প্রত্যেকের পূর্ণ বিবরণ), Notifications  (+ প্রধানের জন্য Assistants, Settings)
  Office:                  Employees, Attendance (হাজিরা), Salary calculation (বেতন হিসাব), Attendance summary
                           (উপস্থিতি হিসাব), Notifications  (+ প্রধানের জন্য Assistants, Settings)
  ভাষা: ওপরের ডান দিকে "বাং/EN" বোতাম। লাইট/ডার্ক: চাঁদ/সূর্য বোতাম।

বেতন হিসাবের নিয়ম
  কর্তন = মাসিক বেতন ÷ কর্মদিবস × অনুপস্থিত (A) দিন।  ছুটি (L) কাটা হয় না।
  কর্মদিবস = মাসের দিন - সাপ্তাহিক ছুটি - তালিকাভুক্ত ছুটি (Settings-এ প্রধান ঠিক করেন; ডিফল্ট শুক্রবার)।
  প্রদেয় = বেতন - কর্তন + বোনাস - অন্য কর্তন - অগ্রিম।  "Mark paid" দিলে সেই সারি আর বদলায় না।

সংক্ষিপ্ত পরীক্ষা (আপনি নিজে করে দেখুন)
  অ্যাডমিন: লগইন -> Institutions -> Add institution (Educational) -> কি কপি -> Add institution (Office) -> কি কপি।
            Settings-এ WhatsApp নম্বর দিন -> লগআউট -> লগইন পেজে সবুজ WhatsApp বোতাম ও "Contact admin" চাপলে চ্যাট খোলে কি না দেখুন।
  প্রধান:  Educational-এর কি দিয়ে ক্যাটাগরি "Office" বেছে লগইন করুন -> ব্যর্থ হতে হবে। সঠিক ক্যাটাগরিতে লগইন -> শর্ত -> "No"
            চাপলে লগইন আটকাবে, "Yes" চাপলে ঢুকবে। Students-এ Import list দিয়ে ৩ জন যোগ -> Attendance -> সেভ -> Reports -> নামে চাপুন -> PDF।
            Assistants-এ ৪র্থ জন যোগ করতে গেলে অনুমতি লাগার বার্তা আসবে; Ask the admin।
  Office:  Employees-এ বেতনসহ কর্মচারী -> Attendance -> Salary calculation -> Make salary list -> Edit/Mark paid/Slip।
  সহযোগী:  সহযোগীর কি দিয়ে লগইন -> Salary, Settings, Assistants মেনুতে নেই; হাজিরা ও রিপোর্ট আছে।

কী কী পরীক্ষা হয়েছে / হয়নি (সৎ হিসাব)
  পরীক্ষা হয়েছে (আসল কোড দিয়ে, কম্পিউটারে নকল ডাটাবেসে): লগইন, ক্যাটাগরি মিল না হলে আটকানো, কি মোবাইলের সাথে
  বাঁধা, ভুল চেষ্টার সীমা, শর্তের গেট ও প্রমাণ জমা, শর্ত বদলালে আবার সম্মতি, সহযোগীর সীমা (৩/১০) ও অনুরোধ,
  প্রতিষ্ঠানের ডাটা আলাদা থাকা, সহযোগীর অধিকার, হাজিরা, রিপোর্ট, বেতন হিসাব (১৩০টি যাচাই পাস) এবং ব্রাউজারে
  সব স্ক্রিনের ক্লিক-পরীক্ষা (লগইন, অ্যাডমিন, শিক্ষা ও অফিস মেনু, বাংলা, লাইট/ডার্ক)।
  পরীক্ষা হয়নি: আসল Google Apps Script/Sheets-এ চালানো, আসল ফোনে ইন্সটল, WhatsApp চ্যাট আসলেই খোলা,
  এবং PDF নামানো (PDF লাইব্রেরি ইন্টারনেট থেকে আসে, আমার পরিবেশে ইন্টারনেট ছিল না)। প্রথমবার চালিয়ে কোনো সমস্যা হলে
  ত্রুটির বার্তা বা স্ক্রিনশট পাঠান, ঠিক করে দেব।

আমি যে সিদ্ধান্তগুলো নিয়েছি (ভুল মনে হলে বলুন)
  1. সহযোগী: মানুষের তালিকা, হাজিরা ও রিপোর্ট পারবে; বেতন, সেটিংস, সহযোগী ব্যবস্থাপনা ও মুছে ফেলা পারবে না।
  2. বেতন শুধু প্রধান (ও অ্যাডমিন) দেখে; সহযোগী কর্মচারীর বেতনের অঙ্কও দেখে না।
  3. ক্যাটাগরি তৈরির সময় আপনি ঠিক করেন সেটি "Education" না "Office" ধরনের।
  4. প্রমাণে মোবাইল-ডিভাইসের তথ্য (ব্রাউজার/স্ক্রিন/টাইমজোন) জমা হয়; আইপি অ্যাড্রেস Apps Script থেকে পাওয়া যায় না।
  5. Google Sheets-ভিত্তিক হওয়ায় সামান্য-মাঝারি ব্যবহারের জন্য ঠিক আছে (প্রতি প্রতিষ্ঠানে সর্বোচ্চ ১৫০০ রেকর্ড)।
     অনেক প্রতিষ্ঠান একসাথে চালু হলে ধীর হতে পারে, তখন ডাটাবেস বদলানোর কথা ভাবতে হবে।
  6. মাসের মাঝে যোগ দেওয়া কর্মচারীর বেতন সম্পূর্ণ কর্মদিবস ধরে হিসাব হয় (অনুপস্থিত দিনই শুধু কাটে)।
